## 📦 Project Setup

1. Clone the repository:
```bash
    git clone https://github.com/Ripsudhanpmishra/educase-popx-frontend.git
```

2. Navigate to the project folder:
```bash
  cd custom-note-service
```

3. Install dependencies:
```bash
  npm install
```

4. Start the development server:
```bash
  npm run dev
```
## 🛠️ Tech Stack
